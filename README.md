3. README — SmartBudget Manager
What is it?
SmartBudget Manager is an Excel workbook used to manage monthly income and expenses.
Requirements
• The SmartBudget_Manager.xlsx file.
• Microsoft Excel or compatible spreadsheet software.
Worksheets
• Dashboard: shows totals and the balance.
• Transactions: used to enter income and expenses.
• Categories: lists the expense categories.
How to use it
• Open the Excel workbook.
• Go to the Transactions worksheet.
• Enter your income and expenses.
• Choose the correct category for each expense.
• Check the totals and balance on the Dashboard.
• Save the workbook.
Notes
• Enter information carefully.
• Do not delete or overwrite formulas.
• Save changes regularly.
